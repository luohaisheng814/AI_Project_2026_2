定位 · 只找周边候选

GPS 拿起点，不做营业判断

只有「请推荐」才申请定位；失败给「重试 / 手选已收录景点」。定位≠实时营业、≠拥挤程度。

地图 · 距离与路线

NAVER 深链交系统 App

距离由服务端按坐标算直线；路线/换乘/时间交给 NAVER 地图 App 确认，模型不编造。

资料 · 官网 + 本地库

每条答案标来源与核对时间

登录后并发抓沙下区官网（mId）与本地分类库；抓不到就如实说「未获取到内容」。

安装包（APK）这一层怎么接

启动先落在 setup.html：填电脑地址进联网页，或选「离线使用」跑包内 data.js。MainActivity 存地址到 SharedPreferences；requestLocation() 走 Android 运行时授权再回网页；nmap:// 等 scheme 交系统 App，主框架加载失败回设置页。

如实标注的边界

① 移动定位在规范里仍是「待开发功能」，本版只在手机浏览器/WebView 内用系统定位；② 定位不等于实时营业或拥挤数据；③ 距离是直线，通勤时间以地图 App 为准；④ 两名真人手机对比测试本轮未做，只用模拟器 + 接口自测替代。
