进入首页 / 添加到主屏幕

浏览器打开 http://<电脑IP>:8000/，拿到页面与 manifest；Service Worker 注册后，图标与离线回退页可缓存。

FLOW 02 · 登录

点「登录 / 로그인 / Log in」

弹窗输入用户名密码 → POST /api/login；成功后按钮变「退出」，指示灯转「已联网」，并拉一次 /api/me。

FLOW 04 · 附近景点

点「附近景点」

navigator.geolocation 取坐标（8 秒超时）；失败给提示，也可用 ?lat=&lng= 直接按坐标预览。

解压 → 装依赖 → 起服务；首次运行自动建库并创建 admin，问答与登录链路与原环境一致。

状态与降级

未登录＝纯本地库直出，不联网不调模型；已登录但缺 API Key＝抓官网后本地成稿；定位被拒＝提示并保留坐标预览入口；旧缓存由 SW v4 的「导航网络优先」兜住。

边界（如实标注）

会话在服务进程内存里，重启需重登；局域网 HTTP 下部分手机不给定位权限，需 HTTPS 隧道或坐标预览；安卓 APK 仍是离线版，不含本图里的登录与联网能力。
